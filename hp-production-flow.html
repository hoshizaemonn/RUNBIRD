各ステップの詳細

1ヒアリング（シート記入）

お客さんと一緒にシートを埋める。聞くのは以下だけ。

必須で聞くこと 何に使うか
基本情報（店舗名・住所・電話・営業時間） アクセスページ・フッター・Googleマップ埋め込み
業種 ページ構成のテンプレ選択・お悩みセクション・FAQ仮作成・画像の方向性
事業概要 サービス紹介セクション・FVのサブコピー
強み 「選ばれる理由」セクション（3カード型）
ゴール CTAの種類と文言（電話予約 / LINE / フォーム等）
サイトの雰囲気 配色・フォント・レイアウトの方向性

メニュー・お客さまの声・FAQ・写真は任意。なければ業種テンプレで仮作成。後から差し替え可能。

2構成・テキスト生成（AI自動）

ヒアリングのJSONデータをもとに、ページ構成と各セクションのテキストを自動生成します。

例：訪問理美容サロン「さるる」の場合

入力データ：
事業概要：「高齢者施設や自宅に出張してカット・カラー・パーマを行う」
強み：「国家資格保有 / 施設との提携実績50件以上 / 土日祝も対応」
↓ AIが各セクション用にリライト・膨らませる

FVキャッチコピー：「美容室に行けない」をなくしたい。ご自宅・施設に、プロの技術をお届けします。

お悩みセクション：「足腰が弱くて美容室に行けない」「施設の散髪は希望の髪型にならない」「家族がカットしているが限界」

選ばれる理由：①国家資格を持つスタイリストが担当 ②施設との提携実績50件以上 ③土日祝も対応

サービス紹介：高齢者施設やご自宅に訪問し、カット・カラー・パーマを行います。サロンと同じ技術を、お好きな場所で。

メニュー：（記入があればそのまま使用、なければ訪問理美容の相場で仮作成）

FAQ：（記入があればそのまま使用、なければ「出張費は？」「車椅子でも大丈夫？」等を仮作成）

CTA：「まずはお電話でご相談ください」（ゴール＝予約を増やしたい）
ポイント：ゼロから文章を創作するのではなく、お客さんが書いた事実（事業概要・強み）をベースに、各セクションに合った文体・長さに整形する仕組みです。動画の台本生成と同じ考え方です。

4SWELL構築（AI＋人）

生成されたテキスト・画像をSWELLのブロックに配置してページを組み立てます。

やること 方法 担当
ブロック配置 セクションごとにSWELLブロック（フルワイド・カラム・FAQ等）を配置 AI → REST API で自動投稿
テキスト流し込み Step 2で生成したテキストを各ブロックに挿入 AI → 自動
画像配置 Step 3で生成した画像を各ブロックに挿入 AI → 自動
配色・フォント設定 雰囲気の選択に合わせてSWELLカスタマイザーで自動設定 AI → 自動
参考サイトへの寄せ 参考サイトのレイアウト・配色・余白感を解析して自動反映 AI → 自動
ブログページ SWELLの投稿一覧ブロックで自動配置（全案件共通） 自動
問い合わせフォーム ゴール＋問い合わせ方法に応じて設置 人が設定
Googleマップ埋め込み 住所からアクセスページに自動配置 自動

5微調整・納品（人）

自動生成されたサイトを確認し、最終調整を行って納品します。

やること 内容
実写写真の差替え お客さんから届いた写真があれば、AI生成画像と入れ替え
ロゴの差替え 実物のロゴがあれば仮ロゴと入れ替え
テキストの修正 お客さんに確認してもらい、事実と異なる部分を修正
メニュー・料金の確定 仮で入れていた場合、実際の料金に差替え
FAQ・お客さまの声 仮で入れていた場合、実際の内容に差替え
スマホ表示確認 レスポンシブの崩れがないか確認
SEO基本設定 タイトル・ディスクリプション・OGP設定
公開・納品 クライアント最終確認→公開

まとめ：何が自動で、何が人の仕事か

工程 AI自動 人の仕事
ヒアリング — お客さんと一緒にシート記入
ページ構成 業種×ゴールで自動決定 —
テキスト生成 事業概要・強みから全セクション自動生成 事実確認・微修正
画像生成 業種×雰囲気×セクションで自動生成 実写が届いたら差替え
ロゴ 店舗名から仮ロゴ自動生成 実物があれば差替え
SWELL構築 ブロック・テキスト・画像・配色・レイアウトすべて自動配置 最終確認・微調整のみ
FAQ・メニュー 業種テンプレで仮作成 実際の内容に差替え
公開 — 最終確認・SEO設定・公開
結果：AIが全体の70〜80%を自動生成し、人は「確認・差替え・微調整」に集中。ヒアリングから初稿完成まで大幅に時間を短縮できます。
