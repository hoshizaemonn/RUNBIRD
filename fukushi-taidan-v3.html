BLOCK 10:00-0:40
冒頭・河合の言い切り（ここだけ台本通り）
狙い: ゲストに実績を自慢させない。河合が数字込みで言い切り、ゲストは自己紹介だけでいい状態に。
  • A: 「福祉未経験から◯ヶ月で満室、現在月商◯◯万円の◯◯さんです」
  • B: 「加盟◯ヶ月目・物件契約済み、開業準備まっただ中の◯◯さんです」
  • C: 「融資支援◯件、◯◯を担当してきた◯◯です」／ D: 「開設から◯年、入居者◯名を見てきたサビ管の◯◯さんです」
BLOCK 20:40-4:00
ビフォー — 努力×結果のギャップ＋感情
狙い: 感情の言葉が出るまで粘る。心理的天井（「自分には無理だと思っていた」）と、セリフで再現できる場面を1つ取る。
  • 「まず何から始めました?」→「どのくらいの期間?」→「結果どうでした?」→「その時、正直どういう気持ちでした?」
  • しんどかった瞬間: 「相手、何て言ったんですか?」→ セリフで再現させる（テロップ最大の見せ場）
BLOCK 34:00-7:00
転機 — 出会いと「迷い」
狙い: 迷った人が決めた理由こそ検討者が一番聞きたい情報。加盟を迷った話を飛ばさない。
  • 「どこで知ったんですか?」「正直、FCって怪しいと思いませんでした?」（視聴者代弁・河合から言う）
  • 「どのくらい迷いました? 何がネック?」「最後の決め手は?」／ 制度説明（加盟金0円等）は河合が30秒で補足（ゲストに営業させない）
BLOCK 47:00-11:00
変化 — 何をしたら何が変わったか（1対1）
狙い: 再現可能なメソッドとして語らせる。「やったこと→変わった数字」をセットで。正直なマイナスを必ず1つ。
  • 事業計画（部屋数・管理者兼務）／ 融資（3パターン計画・想定Q&A）／ 入居者集め（開設前の挨拶回り）から該当分
  • 「逆に、想定と違ったこと・大変だったことは?」← 良い話だけの対談は借り物に見える。正直さが信頼の核
BLOCK 511:00-14:00
アフター — 数字の確定と生活の変化
狙い: 数字をレイヤー別に聞き、河合が復唱驚きで1つずつ確定。お金以外の変化＝福祉はここが刺さる。
  • 「今、入居◯名で月商が——?」（復唱）「手元にはどのくらい残る感覚?」（言えなければ前職比較に切替）
  • 「収入以外で生活変わりました?」「ご家族は今、何て?」「入居者さんやご家族から言われて印象に残ってる言葉は?」
BLOCK 614:00-17:00
後悔・時間価値 → これからの人へ
狙い: 「なぜもっと早くやらなかったんだろう」の福祉版を本人の言葉で。台本で3ヶ条を与えない。
  • 「もし加盟してなかったら、今どうなってたと思います?」「1人で調べてた◯ヶ月、今振り返るとどうですか?」
  • 「最後に、これから考えてる人へ」＋ ショート用の30秒言い切り×3テーマ（「1人で調べてる人へ」「お金の不安がある人へ」「家族に反対されてる人へ」）
BLOCK 717:00-18:00
締め・CTA（河合のみ・別撮り可）
狙い: 河合が教訓を一般化して総括 → 資料請求LINE → 次回予告。
  • 「◯◯さんが特別だったんじゃなく、"1人で調べる"のをやめて数字で設計するやり方に切り替えたことが大事」→ LINEで収支シミュレーション3パターンのサンプル送付 → 次回ゲスト予告＋チャンネル登録
