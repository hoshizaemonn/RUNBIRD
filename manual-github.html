0. そもそもGitHubで何をするのか

ナレッジファイルを編集したら、その変更を全員で共有するためにGitHubに反映します。

ファイルを編集 → add（まとめる）→ commit（記録する）→ push（共有する）

逆に、他の人が変更した内容を取り込むには pull（取得する）を使います。

覚えるコマンドは add, commit, push, pull の4つだけです。

1. 自分の変更をGitHubに反映する

ファイルを編集・保存した後、ターミナル（Ctrl + `）で以下を順番に実行します。

ステップ1：変更をまとめる

git add -A

「変更したファイルを全部まとめる」という意味です。

ステップ2：変更を記録する

git commit -m "埼玉県の法令情報を更新"

「何を変えたか」をメッセージとして記録します。日本語でOK。後から見返せるように、何を変えたか書いてください。

ステップ3：GitHubに反映する

git push

これで全員が最新のナレッジを使えるようになります。

3つまとめて実行する場合はこう打てます：
git add -A && git commit -m "変更内容" && git push

2. 他の人の変更を取り込む

他の人がナレッジを更新した場合、自分のPCにも反映する必要があります。

git pull

これだけです。最新のナレッジがダウンロードされます。

作業を始める前に毎回 git pull を実行するのがおすすめです。常に最新の状態で作業できます。

3. 今何が変わっているか確認する

変更されたファイルを見る

git status

赤い文字で表示されたファイル = まだGitHubに反映されていない変更があるファイルです。

何がどう変わったか見る

git diff

追加した行は緑、削除した行は赤で表示されます。

4. 過去の変更履歴を見る

git log --oneline -10

直近10件の変更が「いつ・誰が・何を変えたか」のリストで表示されます。

# 表示例
7cbaf2f 埼玉県の法令情報を更新
a1b2c3d 苦情対応の返信例を追加
e4f5g6h ナレッジベース初期構築

5. 間違えたときの対処

まだ push していない場合

状況コマンド
編集を元に戻したい（保存前）Ctrl + Z（Cursorで何度でも戻せる）
add を取り消したいgit reset
commit を取り消したいgit reset --soft HEAD~1

既に push してしまった場合

自分で対処せず、斗（星崎）に連絡してください。安全に元に戻します。

push した後に無理に戻そうとすると、他の人の変更も消えてしまう可能性があります。必ず相談してください。
