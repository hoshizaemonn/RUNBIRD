Cursorの使い方マニュアル

ランバード様 福祉事業ナレッジAI環境

1. Cursorの画面の見方

Cursorを開くと、主に3つのエリアがあります。

エリア場所何があるか
サイドバー左側フォルダとファイルの一覧（ナレッジ/返信例/ 等）
エディタ中央ファイルの中身を見る・編集する場所
AIチャット右側 or パネルAIに質問する場所
サイドバーが見えない場合は Ctrl + B で表示/非表示を切り替えられます。

2. AIチャットの開き方

AIに質問するには、チャットパネルを開きます。

操作ショートカット説明
AIチャットを開くCtrl + L右側にチャットパネルが開く
インラインで質問Ctrl + Kエディタ上で直接AIに指示できる
新しいチャットを始めるCtrl + Shift + L過去の会話をリセットして新規開始
基本は Ctrl + L でチャットを開いて質問するだけでOKです。

3. AIへの質問の仕方

チャット欄に日本語で質問を入力するだけです。AIが自動でナレッジを参照して回答します。

例1：返信文を作ってもらう

入力：「利用者のご家族から、通所日の変更について問い合わせが来ました。返信を作成してください。」

AI：ナレッジ/返信例/利用者家族への連絡.md を参照して、スケジュール調整の返信文を生成

例2：法令について確認する

入力：「事故報告は発生から何日以内に提出する必要がありますか？」

AI：ナレッジ/法令/ のファイルを参照して回答

例3：NGラインを確認する

入力：「この返信文に法令上問題がないかチェックしてください」

AI：触れてはいけないライン.md と照合して、問題があれば指摘

質問のコツ

  • 何をしてほしいか具体的に書く（「返信して」「チェックして」「教えて」）
  • 状況を伝える（「家族から○○の問い合わせが来た」）
  • 対象を明確にする（「埼玉県の」「Royal事業所の」）

4. 特定のファイルをAIに読ませる

AIに特定のナレッジファイルを確実に参照させたい場合は、チャット欄で @ を使います。

# チャット欄に入力する例

@ナレッジ/法令/埼玉県.md
この県の事故報告の期限を教えてください

@ を打つとファイル名の候補が出てくるので、選択するだけです。

通常は .cursorrules の設定で自動的にナレッジを参照しますが、確実に特定ファイルを読ませたい場合に使います。

5. ファイルの見方と編集

ファイルを開く

  • 左のサイドバーで「ナレッジ」フォルダをクリックして展開
  • 見たいファイル（例：「利用者家族への連絡.md」）をクリック
  • 中央のエディタにファイルの中身が表示される

ファイルを編集する

  • 開いたファイルの中身を直接書き換える（普通のメモ帳と同じ）
  • Ctrl + S で保存
  • GitHubに反映する（→ GitHubマニュアル参照）
ファイルを編集したら、必ず Ctrl + S で保存してください。保存しないとAIが最新の内容を読めません。

6. ターミナルの開き方

Gitコマンド（プッシュ・プル等）を実行する場所です。

操作ショートカット
ターミナルを開く/閉じるCtrl + `（バッククォート）

画面の下部に黒い画面（ターミナル）が表示されます。ここにGitコマンドを入力します。

ターミナルが怖く感じても大丈夫。使うコマンドは数個だけです（→ GitHubマニュアル参照）。

7. よく使うショートカットまとめ

やりたいことショートカット
AIチャットを開くCtrl + L
新しいチャットを開始Ctrl + Shift + L
インラインでAIに指示Ctrl + K
ファイルを保存Ctrl + S
サイドバーの表示/非表示Ctrl + B
ターミナルを開くCtrl + `
ファイルを素早く開くCtrl + P

8. 困ったとき

症状対処法
AIが返事しないCursorにログインしているか確認。右下のアカウントアイコンをクリック
ナレッジを参照してくれないフォルダが正しく開かれているか確認。File → Open Folder でやり直す
ファイルが見つからないCtrl + P でファイル名を検索
間違って編集してしまったCtrl + Z で元に戻す。保存前なら何度でも戻せる
上記で解決しない斗（星崎）に連絡してください
