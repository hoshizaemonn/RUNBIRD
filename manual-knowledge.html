ナレッジ投入・編集マニュアル

ランバード様 福祉事業ナレッジAI環境

1. フォルダ構成（これを崩さないこと）

📁 ナレッジ/
├── 📁 返信例/ ← ベテランの返信パターンを入れる
│ ├── 利用者家族への連絡.md
│ ├── 行政への報告.md
│ ├── 他施設との連携.md
│ ├── 苦情対応.md
│ └── （ここに新しいファイルを追加）
├── 📁 法令/ ← 法令・制度情報を入れる
│ ├── 共通ルール.md
│ ├── 埼玉県.md
│ ├── 触れてはいけないライン.md
│ └── （県が増えたらファイルを追加）
└── 📁 事業所/ ← 事業所固有の情報を入れる
├── Royal.md
└── （事業所が増えたらファイルを追加）
フォルダの名前を変えたり、新しいフォルダを勝手に作ったりしないでください。AIが参照できなくなります。

2. 新しいナレッジファイルを追加する

例：新しい返信パターンを追加したい

  1. 左のサイドバーで「ナレッジ → 返信例」フォルダを右クリック
  2. 「New File」をクリック
  3. ファイル名を入力（例：契約更新の案内.md）
    ※必ず .md をつけること
  4. 下のテンプレートに沿って中身を書く
  5. Ctrl + S で保存
  6. GitHubに反映する（→ GitHubマニュアル参照）

3. 返信例の書き方テンプレート

全ての返信例は同じフォーマットで書いてください。AIの理解精度が上がります。

テンプレート（コピーして使ってください）

# ○○○○（ファイルのテーマ）

## ○○の場合

### パターン
どんな状況で使うか（例：家族から○○について聞かれた場合）

### 返信例
```
○○様

いつもお世話になっております。
（返信文をここに書く）
```

### ポイント
- この返信で気をつけること1
- この返信で気をつけること2
- この返信で気をつけること3

---

## △△の場合

### パターン
（別のパターンを同じ形式で追加）

### 返信例
```
（返信文）
```

### ポイント
- ポイント1
- ポイント2
必ず「パターン → 返信例 → ポイント」の3点セットで書いてください。この形式が統一されていることがAIの精度に直結します。

6. 既存のナレッジを編集する

  1. 左のサイドバーで編集したいファイルをクリックして開く
  2. 中身を直接書き換える（普通のメモ帳と同じ）
  3. Ctrl + S で保存
  4. GitHubに反映する（→ GitHubマニュアル参照）

よくある編集パターン

やりたいことやり方
新しい返信パターンを追加既存ファイルの末尾に --- を入れて、同じ形式で追加
返信例を修正該当の返信例の部分を直接書き換え
法令が改正された該当県のファイルを更新 + 更新履歴に記録
NGラインを追加触れてはいけないライン.md に同じ形式で追加

7. やってはいけないこと

NG理由
フォルダ名を変えるAIが参照できなくなる
フォルダの外にファイルを置くAIが見つけられない
.cursorrules を編集するAIの動作が変わってしまう。変更は斗に相談
テンプレートと違う形式で書くAIの理解精度が下がる
法令を変更して更新履歴に書かないいつ変わったか追跡できなくなる

8. まとめ：ナレッジ投入の全体の流れ

  1. git pull で最新の状態にする
  2. ファイルを新規作成 or 既存ファイルを編集
  3. テンプレートに沿って内容を記入
  4. Ctrl + S で保存
  5. git add -A && git commit -m "変更内容" && git push
  6. 完了。次からAIが最新ナレッジで回答する
