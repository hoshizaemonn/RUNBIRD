施策3: ランディングページの改善

今週中に対応

3-A: スマホ固定CTAボタンの設置（業界標準）

競合はほぼ全社やっています。 オトロン（4ボタン）、カートルズ（4ボタン）、カーマッチ（3ボタン）、COCOCAR（4ボタン）など、 自社ローン業界では画面下部の固定CTAバーが業界標準です。
推奨: 2ボタン固定バー
LINEで相談する
フォームで相談する
画面下部に常に固定表示 → いつでもタップ可能
競合各社の固定CTA構成:
競合ボタン数構成
オトロン4LINE / お気に入り / 事前審査 / 在庫一覧
カートルズ4車両検索 / LINE / お問合せ / 電話
COCOCAR4ローン申込 / 電話 / LINE / お問合せ
カーマッチ足立3電話 / LINEで仮審査 / メール問合せ
結論: 固定CTAバーは業界標準。2ボタン（LINE + フォーム）の追従がベスト。 競合は3〜4ボタンが多いですが、シンプルな2ボタンの方が迷わずタップしやすく、CVR向上に効果的です。

3-B: FAQ直後にCTAを追加配置

ヒートマップの結果、FAQ（65〜70%地点）にユーザーが最長1分32秒滞在しています。 ここが「不安を解消して行動する」タイミングです。
現状: FAQ後にCTAが弱い
改善: FAQ直後に大きなCTAを設置
推奨CTA文言:
「不安が解消されたら、まずはLINEで気軽にご相談ください。しつこい営業は一切ありません。」

施策4: LINE導線の最適化

CVR改善

施策6: クリック詐欺対策

3週目以降
クリック詐欺（アドフラウド）とは？
Google広告は「クリックされるたびに課金」されます。
クリック詐欺とは、実際のお客様ではないボット（自動プログラム）や競合他社が、 わざと広告をクリックして広告費を無駄に消費させる行為です。
クリックされた時点で課金されるため、問い合わせにつながらない「空クリック」でお金だけ減ります。

誰がやっているのか？

1. ボット（自動プログラム）
  インターネット上を自動巡回し、広告を無差別にクリック。
  Clarityで3セッション検知済み。

2. 競合他社（可能性）
  ライバル店が意図的に広告をクリックし、
  広告費を消費させて予算切れを狙うケース。

3. 広告収益目的のサイト
  ディスプレイ広告の場合、自分のサイトに貼った広告を
  クリックさせて収益を得る手口。
  （今回は検索広告なので該当しにくい）

業界統計: Google広告全体で約11.5%のクリックが不正と言われています。 Googleの自動フィルターで一部は防げますが、IPアドレスを変えたり端末を偽装する高度なボットは検知できません。

対策方法

方法1: 専用ツールを導入（推奨）
  不正クリックを自動検知し、そのIPアドレスを
  Google広告の除外リストに自動追加するツール。
  3秒以内にブロックできるものもあります。
ツール月額特徴
Spider AF ¥5,000〜 日本製。日本語サポート。導入が簡単。
ClickCease ¥7,000〜 海外製。検知精度が高い。
月¥5,000のツール代 → 月¥21,600の節約 = 差し引き月¥16,600のプラス
方法2: 手動で対策（無料だが手間）
  Google広告の管理画面で怪しいIPアドレスを
  手動で除外設定する。ただし上限500件まで。

時間帯別パフォーマンス

2/20〜2/21

2/21（土）時間帯別 詳細

土曜日は8〜9時と14〜20時に2つのピークがあります。 朝の通勤・起床時間帯と、午後のリラックスタイムに検索需要が高まる傾向です。
