CLARITY INTEGRATION GUIDE

Microsoft Clarity 導入ガイド

LPで「どこが見られて、どこで離脱したか」を可視化するための導入手順

WHY

📌 なぜClarityが必要か

現状、GA4で「LPに来た／何秒滞在した／スクロール率22%」までは分かりますが、以下が見えていません：

  • ❌ FV（ファーストビュー）で離脱したのか、比較表まで読んだのか
  • ❌ どのボタンが押されてどのボタンが無視されたのか
  • ❌ フォーム入力中にどの項目で詰まったのか（4月のフォーム完了率50%急落の真因）

これらを無料で・タグ1行で・即日取れるようにするのがMicrosoft Clarityです。

FEATURES

✨ Clarityでできる3つのこと

🔥
クリックヒートマップ
どこが押されてるか
📜
スクロールヒートマップ
どこで離脱したか
🎬
セッション録画
実際の動きを動画で再生

特にOWLで効果が出そうな分析

  • フォーム完了率の真因究明：4月に100→50%に急落した原因が、セッション録画で見える
  • LP改修の根拠取得：3案モックアップのどれが効きそうか、現状のヒートマップから判断
  • 広告との連携：CV出ない広告のクリック後、LPで何が起きてるか可視化
SETUP STEPS

🛠 導入手順（所要時間：15分）

  1. Microsoft Clarityにアカウント作成
    https://clarity.microsoft.com/ でMicrosoftアカウント or Googleアカウントでログイン（無料）
  2. 新規プロジェクトを作成
    プロジェクト名：「OWL福祉事業LP」
    ウェブサイトURL：https://owl-fukushi.net
    サイトのカテゴリ：「ビジネスサービス」または近いもの
  3. トラッキングコード（タグ）を取得
    プロジェクト作成後、「設定」→「セットアップ」でJavaScriptタグが表示される。下記のような形：
    <script type="text/javascript"> (function(c,l,a,r,i,t,y){ c[a]=c[a]||function(){(c[a].q=c[a].q||[]).push(arguments)}; t=l.createElement(r);t.async=1;t.src="https://www.clarity.ms/tag/"+i; y=l.getElementsByTagName(r)[0];y.parentNode.insertBefore(t,y); })(window, document, "clarity", "script", "XXXXXXXXXX"); </script>
    XXXXXXXXXX の部分が固有のプロジェクトID
  4. WordPressにタグを設置
    3つの方法のどれか：
    • A: テーマの header.php に直接埋め込む（WPテーマ編集権限が必要）
    • B: 「Insert Headers and Footers」プラグインで <head> 内に貼る（推奨・簡単）
    • C: GTM経由で配信（GTMが既に入っていれば）
  5. 動作確認
    タグ設置後、自分のスマホ・PCでLP（lp_zero-plan-g/）にアクセス → Clarityダッシュボードで「セッション」に自分の訪問が記録されるか確認（数分で反映）
  6. データ蓄積（最低3〜7日）
    最低3日、できれば1週間データを溜めると分析できるレベルになる
PRIVACY

🔒 プライバシーの扱い（重要）

  • Clarityは個人特定情報（PII）を自動マスキングします
  • フォーム入力フィールドの中身（氏名・メール等）はデフォルトで録画されません（マスキング表示）
  • クッキーは使用されますが、Microsoft の取り扱いに準拠
  • サイトのプライバシーポリシーに「行動分析ツールを使用」と1行追記しておくのが望ましい
嶋田社長への確認事項：タグの追加が必要なので、WordPress編集の許諾が必要です。承諾いただければ星崎で設置作業を進めます。
ANALYSIS

📊 導入後の分析フロー

1週間後の最初の分析（推奨）

  1. スクロールヒートマップでLP全体の到達率を見る
    「FVで離脱25%、比較表で30%、CTAまで45%」など、どこで何%が落ちているか可視化
  2. クリックヒートマップで反応箇所を見る
    「電話番号は押されているか」「資料請求ボタンの色違いどっちが押されているか」など
  3. セッション録画で離脱パターンを観察
    10〜20件の録画を流し見し、共通の離脱ポイントを特定
  4. フォーム特化の分析
    フォーム入力途中で離脱したセッションを抽出 → どの項目で詰まったかを特定
