MEASUREMENT VERIFICATION — 6/1〜

計測確認手順書（GA4でUTM識別）

6/1の新キャンペーン配信開始後、UTMが正しくGA4に届いてCVが分解できているかを確認する手順

BACKGROUND

📌 なぜ確認が必要か

これまで Yahoo広告のCVがGA4で識別できていなかったのは、UTM未設定だったため。今回各広告にUTMを付与したので、6/1配信開始後に本当に動いているか実測確認が必要です。

確認したい3つのこと

  • Yahoo広告：GA4で「yahoo / cpc」が出現するか（これまで出ていなかった）
  • Google広告：GA4で「google / cpc」が継続して識別されているか
  • キャンペーン別：utm_campaignで CP01/CP02/CP03 の内訳が見えるか
STEP 1 — 6/1配信開始直後

⚡ リアルタイムで「届いてるか」確認

配信開始から30分〜数時間で、クリックが発生したらリアルタイムで見えるはずです。

  1. GA4を開く
    GA4プロパティ「OWL福祉事業LPサイト」を開く
  2. 左メニュー「レポート」→「リアルタイム」
    過去30分のアクセスがリアルタイムで見える
  3. 「ユーザーの最初のメディアでユーザー数を確認」カードを探す
    またはディメンションを「セッションのソース/メディア」に変える
  4. 下記が出現するかチェック
    yahoo / cpc ← 新登場（これまで0だった） google / cpc ← 継続（これまでも出ていた）
OKパターン：「yahoo / cpc」が新たに出現していたら成功。「google / cpc」も継続していればOK。
NGパターン：「yahoo / cpc」が一切出ない / 「(direct) / (none)」のままYahoo分が紛れている → UTM設定要再確認。
STEP 2 — 6/3〜6/5（数日後）

📊 チャネル別のCV内訳を確認

数日経って数件CVが出てきたら、ソース/メディア別のCV内訳が見えます。

  1. レポート → エンゲージメント → コンバージョン
  2. テーブルの行を「セッションのデフォルトチャネルグループ」または「セッションのソース/メディア」に変更
  3. contact_complete の行を見る
    下記のように分解されているのが理想：
    ソース/メディア期待される件数
    yahoo / cpc1件〜（Yahoo広告経由）
    google / cpc1件〜（Google広告経由）
    (direct) / (none)これまでより減るはず（Yahoo分が抜けるため）
STEP 3 — 1週間後

🎯 キャンペーン別の内訳を確認

utm_campaign の値（CP01_franchise / CP02_kaigyo / CP03_test）でキャンペーン別のCV件数・CPAが見えます。

  1. レポート → 集客 → トラフィック獲得
  2. テーブルの行を「セッション キャンペーン」に変更
  3. 下記のキャンペーン名が表示されるか確認
    CP01_franchise（Yahoo・Google 本命） CP02_kaigyo（Yahoo・Google 派生） CP03_test（Yahoo・Google テスト）
  4. 各キャンペーンのCV件数を比較
    どのキャンペーンが効率良くCVを生んでいるかが分かる → 予算配分の判断材料に
TROUBLESHOOTING

⚠️ もし「yahoo / cpc」が出てこない場合

UTMが効いていない原因と対処法：

症状原因対処
yahoo / cpc が0UTMが付いていない／消えているYahoo広告管理画面で各広告の最終リンク先URLにUTMが入っているか確認
yahoo / referral として出るUTM_medium=cpc になっていないURL を再確認、特に medium=cpc を入れ直し
(direct) / (none) が異常に多いLP側のリダイレクト等でUTMが落ちているWordPressやCloudflareの設定確認、必要なら .htaccess で UTM 保持
Yahoo CV が広告管理画面とGA4で違うYCLID と UTM の競合Yahoo広告の「自動タグ機能」設定を確認
CHECKLIST

✅ 確認チェックリスト（6/1〜）

  • 6/1 配信開始：GA4リアルタイムで「yahoo / cpc」が出現
  • 6/1 配信開始：GA4リアルタイムで「google / cpc」が継続
  • 6/3 数日後：contact_complete が yahoo/cpc 経由で1件以上記録
  • 6/3 数日後：contact_complete が google/cpc 経由で1件以上記録
  • 6/8 1週間後：CP01/CP02/CP03 のキャンペーン名がGA4で確認できる
  • 6/8 1週間後：各キャンペーンのCV件数・CPAが算出できる
