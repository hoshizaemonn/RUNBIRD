キャンペーン設定手順
（Google広告 ／ Yahoo広告）

設定レシピの内容を、実際の管理画面で設定する手順。自分で設定する時も、代理店に渡す指示書としても使えます。

株式会社 斗（hishaku）
PRE-CHECK

⚠️ 着手前の3つの前提

  1. アカウントへのアクセス権
    自分で設定するなら管理者/編集権限が必要。代理店運用なら「この内容で設定して」と本手順を渡す。
  2. コンバージョン計測の設定
    「資料請求完了（/thanks/到達）」をCVとして計測できる状態にする。これが無いとCV最適化できない。GA4のcontact_completeを各媒体にインポート or 媒体側タグを設置。
  3. フォームの動作確認
    4月に完了率が落ちた件。設定前にフォームが正常に送信できるかテスト（別資料：フォーム原因究明チェックリスト）。

🟣 Yahoo広告 検索広告の設定手順

管理画面：Yahoo!広告 → 検索広告。アカウント（ランバード / ID 1441736）にログイン。

STEP 1〜9

  1. キャンペーンを3つ作成
    「+キャンペーン作成」→ 目的「コンバージョン」。下記3本を作る。
    キャンペーン名月予算
    CP01_本命_フランチャイズ¥210,000（日¥7,000）
    CP02_派生_開業全般¥150,000（日¥5,000）
    CP03_テスト_新規KW¥60,000（日¥2,000）
  2. 入札戦略を設定
    まず「コンバージョン数の最大化」。CVデータが少ない初期は「クリック数の最大化＋CPC上限¥1,000」でも可。蓄積後に切替。
  3. 広告グループを作成
    各キャンペーン内に1〜2グループ。命名は「本命KW」「派生KW」など中身がわかる名前に（現状の"全部同じ名前"を解消）。
  4. キーワードを登録（フレーズ一致）
    CP01に本命、CP02に派生を入れる。

    ※「福祉 フランチャイズ」は広すぎるため入れない（削除方針で確定）。
  5. 除外キーワードを登録
    ツール → 対象外キーワードリスト → 全キャンペーンに適用。
    レンタルスペース / 在宅 / リフォーム / 木造 / ダイヤチェアー 介護タクシー / 飲食 / カフェ / 塾 / 学習塾 安い / 格安 / 無料 / 口コミ / 評判 求人 / バイト / パート / 転職 / 就職 入居 / 入所 / 利用 / 申込み / 体験
  6. 広告文を登録
    タイトル・説明文は別資料「Yahoo広告 設定レシピ／広告文」をコピペ。電話番号 0120-540-522 を含める。

    https://owl-fukushi.net/lp_zero-plan-g/?utm_source=yahoo&utm_medium=cpc&utm_campaign=CP01_franchise
    ★最重要。これでGA4にYahoo広告のCVが正しく計測される（現状の未計測を解消）。

    合計 日¥14,000。配信地域＝全国。デバイス＝スマホ優先（流入64%）。
  9. 配信オンにして完了
    停止中の「0円プランLP Camp1」等の旧キャンペーンは整理（停止 or 削除）。

🔵 Google広告 検索広告の設定手順

管理画面：Google 広告（ads.google.com）。

  1. 不要なGDN（ディスプレイ）を停止
    最初にやる。即離脱（滞在6.5秒）でムダなので停止 → 浮いた予算を検索へ。
  2. 検索キャンペーンを作成
    目標「リード」→ キャンペーンタイプ「検索」。月予算 ¥250,000（日¥8,300）。
  3. 入札戦略
    「コンバージョン数の最大化」＋目標CPA上限 ¥20,000。CVデータ不足時は「クリック数の最大化」で開始。
  4. キーワードを登録（フレーズ一致）
    "グループホーム フランチャイズ" ¥1,000 "障がい者グループホーム フランチャイズ" ¥1,200 "障害者グループホーム フランチャイズ" ¥1,200 "グループホーム 開業" ¥800 "福祉事業 開業" ¥600 "共同生活援助 開業" ¥500 "グループホーム 加盟金" ¥600 （テスト枠・部分一致）障害福祉 起業 / 福祉ビジネス 始める / 支援事業 開業 ¥500
    ※「福祉 フランチャイズ」は入れない（削除方針で確定）。
  5. 除外キーワードを登録
    求人 / バイト / パート / 転職 / 採用 入居 / 入所 / 利用 / 体験 口コミ / 評判 / 比較サイト / 無料 / 安い / 格安 家族 / 子供 / 高齢者 / 資格 / 講座 / 通信教育
  6. レスポンシブ検索広告を作成
    見出し15本・説明文4本は別資料「Google広告 設定レシピ／広告文」をコピペ。
  7. 遷移先URL＋UTM
    https://owl-fukushi.net/lp_zero-plan-g/?utm_source=google&utm_medium=cpc&utm_campaign=CP01_franchise&utm_term={keyword}
  8. コンバージョン設定
    主CV＝contact_complete（資料請求完了）。電話タップ（tel:0120540522）もCVに。GA4からインポート推奨。
  9. 配信オンにして完了
AFTER LAUNCH

設定後の運用（最初の1ヶ月）

  1. 2週間後：初回チェック
    検索語句レポートを見て、想定外KWが来ていたら除外KWに追加。
  2. 勝ちKWを完全一致に格上げ
    CVが出たKWは完全一致に上げて入札強化。
  3. 負けKWを停止
    クリックは多いがCV0のKWは一時停止。
  4. CV最適化へ切替
    CVが30日で十分貯まったら入札戦略を「コンバージョン数の最大化」に。
最重要ポイント：何よりまずUTM設定とCV計測。これが無いと「どのKWが効いたか」が分からず最適化できません。設定の一番の目的はここです。
