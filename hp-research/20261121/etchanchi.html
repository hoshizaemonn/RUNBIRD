2．各サイトから借りるところ

桔梗が丘整骨院（構成と予約まわりの軸）

体験価格を大きく見せる。

「体験プラン 90分7,500円（通常14,000円）・月5名限定」を料金欄の先頭に置いている。えっちゃん家は「ジュラシック筋膜リリース OPEN記念価格」をここに当てる。

施術の流れ。

問診票 → カウンセリング → 歪みチェック → 説明 → 施術 → 施術後の説明 → 生活のアドバイス → お会計・次回予約、の8ステップ。えっちゃん家は「その日の状態に合わせて提案」を軸に5〜6ステップに縮める。

予約前の確認事項。

予約の前に対応の範囲を伝える。えっちゃん家なら「医療行為ではない」「年配の方には筋膜リリースが合わない場合がある」をここで伝えられる。

受付時間の表、FAQ（6問）、アクセス。
予約導線。

ヘッダーに固定の「LINEで予約」と電話。

立ち位置の違い。

桔梗が丘はFAQで「揉みほぐすマッサージは行っていません」と書いている。えっちゃん家はもみほぐしが入口なので、逆に「もみほぐし＋筋膜リリースを組み合わせられる」をはっきり打ち出せる。

真似しない: 症状別50項目、推薦者8名、資格8件の列挙、予約サービスが5系統以上。

doodle（人柄と安心感）

院長あいさつ。

一人称のやわらかい口調で、なぜこの仕事をしているかを語る。えっちゃん家の代表あいさつは「ホッと緩める」「気負わず立ち寄れる」の言葉で組む。

選ばれる理由4つ。

番号付きで短く並べる。えっちゃん家なら ①ジュラシック筋膜リリース® ②もみほぐしとの組み合わせ ③1人サロンで最初から最後まで同じ人 ④桜木町駅・野毛からの近さ。

ご利用の流れ4ステップ

（オンライン予約 → ヒアリング → 施術 → アフターサポート）とアイコン。

悩みタグ。

「授乳後の肩こり」などをアイコン付きで並べる。えっちゃん家はチラシの「こんな方におすすめ」5つをタグにする。

お客様の声。

「お悩み」「施術内容」のタグ付き。開業直後なので、集まってから足す。

FAQ（13問）。

キャンセルの扱い、保険の扱いなど。

真似しない: 託児、痩身マシン、遺伝子検査、長期コースの価格。

The session（施術の見せ方）

施術ステップを写真付きで。

カウンセリング → ストレッチ → 骨盤調整 → 指圧 → … と7ステップ、各ステップに写真と説明。ジュラシック筋膜リリース®のページはこの型で作る（撮影ありなので写真を当てられる）。

時間で名前を付けたメニュー。

「Short 30分／Standard 60分／Premium 100分」と、初回価格を横に添える。えっちゃん家のもみほぐし60／90／120分に使える。

初回限定の条件を明記。

えっちゃん家のOPEN記念価格の期限・条件をここで書く（要ヒアリング）。

「無理な予約勧誘や回数券の押し売りは一切ありません」。

初めての人の不安に答える一文としてそのまま使える。

真似しない: 機材・物販の多さ、健康効果を言い切る表現（免疫・病気への効果など）。えっちゃん家では効果を断定しない。

Fio Lab.（見た目の質感）

  • 業種は化粧品メーカーなので、構成ではなく見た目の空気感の参考。
  • 余白を広く取る、写真を大きく使い文字を減らす、短いキャッチを前面に置く。
  • えっちゃん家の「清潔・ナチュラル」を、安っぽくならずに出すための基準にする。
