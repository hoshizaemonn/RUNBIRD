セットアップ手順書

ランバード様 Windows PC にナレッジAI環境を構築する手順

1

GitHubアカウントを作成する

まだGitHubアカウントを持っていない場合は作成します。

  1. ブラウザで https://github.com/signup を開く
  2. メールアドレスを入力 → パスワードを設定 → ユーザー名を決める
  3. メールに届く確認コードを入力して完了
ユーザー名は「名前-runbird」など、誰かわかるものにしておくと管理しやすいです（例：tanaka-runbird）
2

Git をインストールする（Windows）

Cursorからナレッジを更新するために必要です。

  1. ブラウザで https://git-scm.com/download/win を開く
  2. 「Click here to download」をクリックしてインストーラーをダウンロード
  3. ダウンロードしたファイルを実行。全てデフォルト設定のまま「Next」を押し続けてインストール
途中でいろいろ選択肢が出ますが、全て初期設定のままでOKです。何も変えずにNextを押し続けてください。

インストール後、Cursorのターミナルで動作確認：

# Gitが入ったか確認（バージョンが表示されればOK）
git --version
3

Git の初期設定をする

Cursorの下のほうにある「ターミナル」を開いて、以下を1行ずつ実行します。

# 自分の名前を設定（GitHubに記録される名前）
git config --global user.name "自分の名前"

# 自分のメールアドレスを設定（GitHubアカウントと同じもの）
git config --global user.email "自分のメールアドレス"
「自分の名前」と「自分のメールアドレス」は、Step 1で作ったGitHubアカウントの情報に合わせてください。
4

ナレッジベースをダウンロード（クローン）する

Cursorのターミナルで以下を実行します。

# デスクトップに移動
cd Desktop

# ナレッジベースをダウンロード
git clone https://github.com/hoshizaemonn/runbird-welfare-knowledge.git

デスクトップに「runbird-welfare-knowledge」というフォルダができます。

初回のクローン時にGitHubのログインを求められます。Step 1で作ったアカウントでログインしてください。
5

Cursor でナレッジフォルダを開く

  1. Cursorを起動
  2. メニューから File → Open Folder をクリック
  3. デスクトップの 「runbird-welfare-knowledge」 フォルダを選択して「フォルダーの選択」

左のサイドバーに以下のフォルダが見えたら成功です：

# こう見えていればOK
📂 ナレッジ/
  ├── 📂 返信例/
  ├── 📂 法令/
  └── 📂 事業所/
6

AIが動くか確認する

Cursorのチャット欄（右サイドバー or Ctrl+L）に以下を入力してみてください。

利用者のご家族から、サービスの利用条件について問い合わせが来ました。
返信文を作成してください。

AIがナレッジを参照して返信文を生成すれば、セットアップ完了です。

AIの回答の最後に「参照: ナレッジ/返信例/利用者家族への連絡.md」のようにファイル名が出ていれば、ナレッジが正しく参照されています。
7

GitHubの権限を設定する（斗が実施）

この作業は斗側で行います。先方はStep 1で作ったGitHubのユーザー名を教えてもらうだけでOKです。

  1. ランバード様のGitHubユーザー名を聞く
  2. https://github.com/hoshizaemonn/runbird-welfare-knowledge/settings/access で招待
  3. 権限レベルを設定（Write or Read）
  4. 招待された側はメールの「Accept invitation」をクリック
+

日常の使い方（セットアップ後）

AIに質問する

Cursorのチャット欄に質問を入力するだけ。AIがナレッジを自動で参照して回答します。

ナレッジを編集した後にGitHubへ反映する

ファイルを編集したら、ターミナルで以下を実行します：

# 変更をまとめる
git add -A

# 変更内容を記録する（メッセージは何を変えたか書く）
git commit -m "埼玉県の法令情報を更新"

# GitHubに反映する
git push
コマンドが難しい場合は、CursorのAIに「この変更をGitHubにプッシュして」と頼むこともできます。

他の人の変更を取り込む

# 最新のナレッジをダウンロード
git pull
