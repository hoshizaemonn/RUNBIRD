GitHub とは？

ひとことで言うと

ファイルの「変更履歴」を全て記録する仕組み
誰が・いつ・何を変えたか、全部残る。間違っても元に戻せる。

世界中の企業が使っている、ファイル管理の世界標準

6 / 12

GitHub の何がいいのか

  • 📝変更履歴が全て残る
    4/1に田中さんが問い合わせ対応.mdを修正 ← こんな記録が自動で残る
  • ⏪元に戻せる
    間違って消しても、1クリックで前の状態に復元できる
  • 👥複数人で使える
    全員が同じファイルを見て、それぞれが編集できる
  • ✅レビュー機能
    変更を「提案」→ 管理者が確認 → OKなら反映、という流れが作れる
  • ☁️クラウド保存
    PCが壊れてもデータは消えない。どのPCからでもアクセスできる
  • 🔒権限管理
    「この人は閲覧だけ」「この人は編集OK」と細かく設定できる
7 / 12

普通のファイル管理との違い

今までのやり方GitHub を使うと
変更履歴 誰が変えたかわからない 全て自動で記録される
元に戻す 上書きしたら終わり いつでも前の状態に戻せる
共同編集 ファイルのコピーが乱立 1つのファイルを全員で管理
確認・承認 勝手に書き換えられる 管理者の確認後に反映
バックアップ PCが壊れたら消える クラウドに自動保存
