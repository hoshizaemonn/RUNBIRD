AIの出力

スタッフが質問すると、AIがナレッジを自動で読み込んで回答を生成する

スタッフ:
「クレームが来た。対応して」

AI:
ナレッジ/返信/クレーム対応
を参照して返信文を生成

→ スタッフは送るだけ
1️⃣ ナレッジファイル = 上手い人の返信パターンや法令情報をテキストで保存したもの。普通のファイルなので誰でも読める・編集できる
2️⃣ Cursor Rules = AIへの「常にこのファイルを見て回答しなさい」という指示。一度設定すれば、AIは毎回自動でナレッジを参照する
3️⃣ ファイルを追加・編集するだけでAIの知識が増える。特別な操作は不要。ナレッジが増えれば増えるほどAIの回答精度が上がる
04 ― 全員がうまく使い続けるための仕組み

🗂️ フォルダ構成を固定する

「返信/」「法令/」「事業所/」のフォルダ分けを最初に決めて、全員がそのルールで保存する

ファイルの置き場所がバラバラになると、AIが見つけられなくなる。
→ フォルダ名と分類ルールを最初に決めて固定

✅ レビューしてから反映

ナレッジの変更は「プルリクエスト」で管理者が確認してから反映する

誰でも勝手に書き換えられると、間違った情報がAIに入る。
→ 変更はまず提案 → 管理者がチェック → OKなら反映

📝 書き方のテンプレを用意

ナレッジの書き方を統一する。「こう来たら → こう返す」の形式で全員が同じフォーマットで書く

書き方がバラバラだとAIの理解精度が落ちる。
→ テンプレートに沿って書くだけにする

🔄 定期的に棚卸しする

月1回、ナレッジの中身を確認。古い情報の更新、不足の追加を行う

法令は更新される。放置すると古い情報でAIが回答してしまう。
→ 定期的にチェックする仕組みをセットで入れる
フォルダ構成固定 + レビュー制 + テンプレ統一 + 定期棚卸し
この4つのルールで、誰が触っても崩れないナレッジ基盤になる
05 ― ナレッジに何を入れるか
返信ナレッジ ― こう来たらAIがこう返す
こう来たら → 利用者家族からのクレーム
AIが生成 → 上手い人と同じ品質の謝罪・事実確認・再発防止の返信文
こう来たら → 他施設からの受入れ打診
AIが生成 → 空き状況・条件・見学案内まで含めた返信文

上手い人の返信パターンをナレッジとして蓄積。AIが参照して自動生成するから、スタッフは送るだけ。

法令・制度ナレッジ ― 県や担当者で変わる情報
県・市ごとの違い → 福岡市と北九州市で制度の運用が異なる場合も、それぞれのルールをナレッジに蓄積
法令の更新 → 法改正があればナレッジを更新。次からAIが最新の法令に基づいて自動で回答
事業所・契約の違い → 担当者や事業所ごとに異なる契約条件・対応パターンもナレッジとして管理

県ごと・担当者ごと・法改正のタイミングで変わる情報が全てナレッジに貯まっていく。AIはそれを参照して回答するから、常に最新かつ正確。
